Import from spreadsheet

Drop in your spreadsheet directly — .xlsx, .xls, or .csv all work. Columns recognized: title (or "course"), category/program, crn/section, instructor (folded into the title so repeated course codes track as separate sections). For .xlsx/.xls, status is read straight from the cell's fill color — green = done, any other color = marked priority, white/no fill = not started — no status column needed (a text status/color column is used instead if one exists). Safe to re-import later with an updated export — a row matched by title to a course already in QuickDash never has its status, priority, assignment, or notes touched, though its category/CRN get backfilled if the new export has a value for them; only unmatched rows are added as new courses.
